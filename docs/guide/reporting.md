# Usage reporting

> Part of the [TeamAI CLI Usage Guide](../usage-guide.md).

---

`teamai pull` commits session and usage counts into the team repo, and `teamai workflow` commits [run records](workflow.md#run-records). Turn that off with:

```yaml
# teamai.yaml
usageReport: false
```

One machine overrides it in that scope's `config.yaml`:

```yaml
usageReportEnabled: false
```

`teamai doctor` says whether reporting is on and where that comes from.

teamai digest

With no reported data yet, the command prints `No team usage data available yet.`

A skill use is counted when the agent calls its skill tool, reads a skill's `SKILL.md`, or the prompt names the skill: `/code-review` at the start of the prompt, `$code-review` in Codex, `/skill:code-review` in Pi. Only skills installed for the tool count, and each skill counts once per prompt. Paths such as `/Volumes/External/project` and URL components are not skill invocations. Previously recorded usage stays.
