# teamai skill

> 本文是 [TeamAI CLI 使用指南](../../usage-guide.zh-CN.md) 的一部分。

---

在 AI 工具里用 `/teamai` 说话。这个 skill 只是为了方便，说出要做的事即可，不用自己去执行。

先装上这个 skill：

```text
安装 teamai skill：https://github.com/Tencent/teamai-cli/tree/main/skills/teamai ，然后加载它。
```

GitHub 打不开时：

```text
请根据 https://skillhub.cn/install/skillhub.md，安装 @user_7be6e993/teamai，然后加载它。
```

装好之后可以直接说：

```text
/teamai 帮我从零搭建团队的 TeamAI
/teamai 帮我加入团队的 TeamAI，仓库地址是 https://github.com/your-org/your-repo
/teamai 帮我把 xxx skill 分享给团队
/teamai 帮我打开 TeamAI 看板
```
