# teamai skill

> Part of the [TeamAI CLI Usage Guide](../usage-guide.md).

---

Talk to it with `/teamai` inside an AI tool. The skill is there for convenience: say what you want done, and leave the steps to it.

Install the skill first:

```text
Install the teamai skill: https://github.com/Tencent/teamai-cli/tree/main/skills/teamai , then load it.
```

Then you can say:

```text
/teamai Help me set up TeamAI for my team from scratch
/teamai Help me join my team's TeamAI, repo URL is https://github.com/your-org/your-repo
/teamai Share my xxx skill with the team
/teamai Open the TeamAI dashboard
```
