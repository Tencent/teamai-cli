# 统一 Dashboard

沿用 logo 的炭黑/蓝色，使用四模块导航、中英文本地化和日间/夜间/跟随系统主题，替换旧版会话布局。全部数据来自现有本机采集器和知识库聚合逻辑。

## 功能对应

| 页面 | 保留功能 |
| --- | --- |
| 总览 | 本机会话状态与计数、六项近 7 天/前 7 天指标、知识覆盖率、维护候选计数、会话列表 |
| 团队执行 | 全部已支持工具、按完整工作目录/工具筛选、活跃和最近结束会话、首条/最近经密钥脱敏的输入摘要及输出预览、时长、最近活动/工具、干预与 Token 计数；支持键盘访问的详情保留全部已捕获输入摘要（最长 200 个字符）、安全渲染的 Markdown 输出及完整明细 |
| 团队上下文 | 原有知识库总量、按类型覆盖率、高频召回图表、可折叠从未召回分组、最近召回月份图表、作者贡献表、数据来源与报告生成时间 |
| 团队改进 | 本机趋势，原有晋升/归档/过期知识候选说明和命令，以及 digest/session-save/share-learnings 命令说明 |

维护命令仍为只读指引，不新增 CLI 命令或浏览器写接口。`/kb-report` 保留原有完整独立报告，含维护控制台。

## 实现

- `dashboard-html.ts` 将 `src/dashboard/` 下的框架、样式、语言字典及浏览器代码内联为单一 HTML，无远程资源或额外资源复制步骤。
- 保留 `/api/sessions`、`/events`、`/api/trends`、`/api/kb-summary`、`/kb-report`；新增 `/api/context`，复用 `buildVizData` 和原有已转义的报告区块渲染器，缓存 30 秒并合并并发请求。
- SSE 失败后自动重连；每 15 秒校准会话，确保无后续钩子事件时仍应用原有空闲与结束后 30 秒保留规则。每 5 秒更新相对时间，不替换获得焦点的会话行。
- 加载失败提供重试；刷新失败时保留并明确标识上次成功的知识库/趋势结果。不将缺失指标伪装成零。
- 本机脱敏输入摘要和输出在 HTML/Markdown 渲染前转义，不上传。知识标题、作者、命令与会话内容不翻译。语言和主题偏好仅存于浏览器，存储受限时仍可使用。
- `generatedAt` 为报告生成时间，不冒充团队同步时间。不添加跨设备实时状态、Recall 渗透率、采用率、自动改进状态机或因果改善结论。

## 费用口径

`/api/trends` 每个时间窗口新增 `avgSessionCostMicros` 和 `pricedSessions`。按首次 Stop 所在的 UTC 七天窗口选取会话，累加其中每个会话已知的已定价请求费用（含恢复执行的请求），除以至少有一个已定价请求的会话数。已知零费用计入；没有定价用量的不计入。估算费用同时展示定价覆盖数，未知模型可能导致估算不完整。

原有 `avgRequestCostMicros`、按请求日期分桶和 digest 统计保持兼容。不能用请求日期总费用直接除以首次 Stop 日期的会话数，这两个总体在跨日或恢复会话时不一致。

### 工作区切换与缺失数据

侧栏支持全部本机会话、用户范围和已安装项目范围。项目分区从 anchor 文件发现；旧安装从启动目录及已有会话目录发现。同一项目的 Git worktree 共享项目范围。用户范围包含不属于已安装项目的会话。全部工作区模式的知识库使用启动时范围，并明确标注。单独范围使用自己的知识库配置、独立报告缓存并阻止旧请求覆盖新范围数据。安装新范围后需重启仪表盘。

完整健康报告分别放在团队上下文（覆盖率、召回、条目、贡献者）和团队改进（维护）中，通过内部导航访问。旧报告 URL 保持兼容，仪表盘不再提供跳转入口。上期缺少样本时显示无已结束会话、无已定价会话或无用量数据，不再显示正在收集。
