# Gitbook 团队成员操作手册

这份手册只保留成员日常需要的操作：初始化、开始工作、提交、修改和合并后同步。

## 1. 第一次接入

### macOS

```bash
brew install gh
gh auth login --hostname github.com --git-protocol ssh --web
npm install -g teamai-cli

git clone git@github.com:memoio/Gitbook.git
cd Gitbook
teamai pull
teamai doctor
```

如果 GitHub 登录超时，且本机代理端口是 `7897`：

```bash
export HTTP_PROXY=http://127.0.0.1:7897
export HTTPS_PROXY=http://127.0.0.1:7897
gh auth login --hostname github.com --git-protocol ssh --web --skip-ssh-key
```

这是单仓库模式，仓库里的 `.teamai/teamai.yaml` 会自动完成本机初始化；成员不要再次执行 `teamai init .`。看到 `All checks passed` 即接入成功。

## 2. 每次开始使用

进入仓库并同步最新内容：

```bash
cd /你的路径/Gitbook
git switch main
git pull --ff-only
teamai pull
```

然后从这个仓库目录启动 AI：

- Codex：在 Codex 中把 `/你的路径/Gitbook` 添加为项目，并在该项目中新建对话。
- Claude Code：在终端执行 `cd /你的路径/Gitbook && claude`。

新对话会加载项目中的 TeamAI Skill、Rule 和 Docs。已经打开的旧对话可能没有新资源；合并新 Skill 后应执行 `teamai pull`，再新建对话。

## 3. 新增或修改内容

先创建自己的分支：

```bash
git switch -c docs/简短主题
```

常用位置：

| 内容 | 路径 |
| --- | --- |
| 团队文档 | `.teamai/docs/` |
| 团队 Skill | `.teamai/skills/<skill-name>/SKILL.md` |
| 团队 Rule | `.teamai/rules/<rule-name>.md` |
| 当前业务代码或普通文档 | 仓库原有目录 |

修改完成后检查：

```bash
git status
git diff
teamai pull
```

新 Skill 可在新开的 Codex 或 Claude Code 对话中测试。可以直接说：

```text
使用 document-logic-diagram skill，把这段文档内容画成逻辑说明图。
```

## 4. 提交修改

```bash
git add <本次修改的文件>
git commit -m "docs: 简要说明本次修改"
git push -u origin HEAD
gh pr create --fill
```

不要直接把工作分支合并到 `main`。在 GitHub Pull Request 中等待其他成员评审。

## 5. 根据评审意见修改

继续在原分支修改，不要重新建 PR：

```bash
git add <修改后的文件>
git commit -m "docs: address review feedback"
git push
```

原 Pull Request 会自动更新。重复修改和提交，直到评审通过。

## 6. PR 合并以后

```bash
git switch main
git pull --ff-only
teamai pull
git branch -d <刚才的分支名>
```

如果合并的是新 Skill 或 Rule，关闭旧 AI 对话并从 Gitbook 项目中新建对话。新对话会加载合并后的版本。

## 7. 上传初始 Markdown 文档

初始原文保存一份不可改的基线，同时复制一份作为后续工作版本：

```bash
git switch -c docs/import-initial-document
mkdir -p .teamai/docs/baseline .teamai/docs/current

cp /初始文档的绝对路径/初始文档.md .teamai/docs/baseline/初始版本.md
cp /初始文档的绝对路径/初始文档.md .teamai/docs/current/当前版本.md

git add .teamai/docs/baseline/初始版本.md \
        .teamai/docs/current/当前版本.md
git commit -m "docs: import initial document"
git push -u origin HEAD
gh pr create --fill
```

以后只修改 `.teamai/docs/current/当前版本.md`，不要修改 `baseline/初始版本.md`。初始文档的讨论、修改和确认都通过新的分支与 Pull Request 完成。

## 8. 常见问题

### AI 看不到新 Skill

```bash
git switch main
git pull --ff-only
teamai pull
teamai list
```

确认 Skill 已列出，然后在 Gitbook 项目中新建 Codex 或 Claude Code 对话。

### 查看环境是否正常

```bash
teamai doctor
teamai status
```

### GitHub 登录超时

确保代理软件正在运行，并给终端设置 `HTTP_PROXY` 和 `HTTPS_PROXY` 后重新执行 `gh auth login`。
