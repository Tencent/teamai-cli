# Document Logic Diagram

Create the diagram artifact, not only a prompt or layout suggestion.

## Visual requirements

- Use a 16:9 landscape canvas.
- Prefer editable SVG. If PNG is required, export exactly 3840 × 2160 pixels.
- Use a pure white background (`#FFFFFF`).
- Use only black (`#000000`) for text, borders, arrows, and connectors.
- Do not use color, gray fills, gradients, shadows, 3D effects, textures, icons, decorative illustration, or decorative borders.
- Use regular rectangles, consistent stroke width, aligned edges, and generous whitespace.
- Keep typography restrained and readable. Use short labels instead of paragraphs inside boxes.
- Use one clear reading direction—normally left to right or top to bottom—and avoid crossing connectors.

## Logical structure

Before drawing, identify the figure's single main claim and the smallest set of relationships needed to explain it. Organize the figure around a clear chain such as:

`input or premise → process or mechanism → intermediate result → final outcome`

Use grouping only when it clarifies hierarchy or parallel paths. Do not add elements that lack a role in the explanation.

## Deliverables

Provide:

1. The SVG file or 4K PNG file.
2. A concise title or figure caption.
3. A short logic explanation in prose that walks through the diagram in reading order and states how the parts lead to the conclusion.

## Final check

Verify the 16:9 ratio, white background, black-only palette, consistent lines, readable labels, sufficient whitespace, absence of overlaps or clipping, and a complete logical path from premise to outcome.
